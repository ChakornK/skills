# Agent Skills

These are custom skills I made for use with AI agents.

## Git Commit
Enforces a simple, human-like commit message style based on conventional commit messages.

```sh
npx skills add https://github.com/chakornk/skills --skill git-commit
```

## Comment Guidelines
Prevents agents from verbosely commenting code or adding "slop" information.

```sh
npx skills add https://github.com/chakornk/skills --skill comment-guidelines
```

## Structured Reasoning
For use with non-thinking or low effort LLMs.

```sh
npx skills add https://github.com/chakornk/skills --skill structured-reasoning
```
